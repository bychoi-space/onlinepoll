# AutoSurvey AI — 지능형 온라인 설문조사 & 쿼터 자동화 플랫폼

실존 표본 쿼터 DB 구축부터 다중 설문 엔진 자동 응답, 실시간 이중화 배치 모니터링, 완료 직전 안전 대기(Pre-Completion Safe Wait)까지 통합 제어하는 웹 기반 설문 자동화 플랫폼입니다.

---

## 주요 기능

- **다중 설문 자동화 엔진 지원**
  - 케이스탯(Kstat) 전통시장 점포주 실태조사 (15단계 + 17단계 조사원 평가)
  - 케이스탯(Kstat) 전통시장 상인회 실태조사 (24단계 + 조사원 평가)
  - 메트릭스 경기도 소상공인 사업체패널 3차 (SNUM=622, 4계정·시트·폐업 연동)
  - 메트릭스 서울시 소상공인 사업체패널 5차 (svyA001~115, 99% 안전 대기)
  - 한국리서치(HRC) 에너지총조사 건물 부문 (기입력 항목 보존 & 91% 안전 대기)
  - 글로벌리서치(GIFT) 제5차 성인문해능력조사 (연령 그룹별 가이드 & Part C 대기)
  - 한국갤럽 귀농귀촌 실태조사 (GPS 주입 · 방문규칙 · 8종 필체 전자서명)
  - 코나체인 화성특례시 청소년 만족도 설문 & 범용 B2B/B2C 설문
- **조사 쿼터 보관함 & 하이브리드 생성기**
  - 온누리상품권 가맹점 마스터 DB + 마켓비즈 기업정보 교차 검증
  - 표준 Excel(`.xlsx`) 업로드·다운로드 및 구글 스프레드시트 실시간 동기화
- **이중화 동시 실행 & 안전 제어**
  - 최대 2개 캠페인 동시 배치(`MAX_CONCURRENT_TASKS=2`) 및 `AsyncLocalStorage` 기반 캠페인별 SSE 로그 격리
  - 동일 외부 조사원 계정 동시 실행 충돌 차단 및 `[배치 중지]` 시 실행 중 브라우저 즉시 종료
  - **완료 직전 안전 대기(`safetyGuard = true`)** 기본 적용으로 제출 전 응답 검수 보장

## 디렉터리 구조

```text
onlinepoll/
├── AGENTS.md                  # 시스템 개발 대전제 및 아키텍처 정의서
├── package.json               # 의존성 및 실행/검증 스크립트 정의
├── src/
│   ├── server.js              # Express 엔트리포인트
│   ├── config/                # 환경변수 부트스트랩 및 초기 캠페인 시더
│   ├── models/                # 캠페인 및 런타임 쿼터 스토어 (원자적 파일 쓰기)
│   ├── services/              # 동시 작업 관리자(task-manager) 및 마스터 DB 빌더
│   ├── routes/                # 인증/SSE, 캠페인, 실행, 외부 동기화, 쿼터 도메인 라우터
│   ├── engine/                # 설문 플랫폼별 Playwright 자동화 러너 & 스크래퍼
│   ├── ai/                    # 범용 설문 의사결정 및 주관식 응답 생성 보조 모듈
│   └── utils/                 # Chromium 런처, 로거, 원자적 저장, 한글 전자서명, 엑셀 유틸
├── public/                    # 웹 대시보드 정적 프론트엔드 (Light SaaS UI)
│   ├── index.html             # 메인 캠페인 대시보드 & 조사 쿼터 보관함 허브
│   ├── survey-detail.html     # 통합 3단계 설문 작업실 (STEP 1 쿼터 · STEP 2 기준점 · STEP 3 실행)
│   ├── quota-builder.html     # 하이브리드 조사 쿼터 생성기
│   ├── quota-detail.html      # 다중 스키마 쿼터 상세 뷰어 및 편집기
│   ├── login.html             # 패스코드 접근 인증 게이트
│   └── modules/               # 설문 유형별 블루프린트 및 쿼터 테이블 ES 모듈
└── scripts/                   # 무중단 재기동(safe-pm2-restart) 및 프론트/백엔드 검증 스크립트
```

## 시작하기

### 1. 환경변수 설정
`.env.example`을 복사하여 `.env`를 생성하고 접근 패스코드 및 외부 연동 계정을 설정합니다. (`.env` 및 `data/campaigns.json`은 Git 추적에서 제외됩니다.)

```bash
cp .env.example .env
npm install
```

### 2. 정적 구문 및 모의 DOM 검증
```bash
npm test
```

### 3. 서버 실행
```bash
npm start
```
